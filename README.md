# Justin Kauff Portfolio

Personal portfolio website showcasing projects, research, and technical experience in robotics, computer vision, embedded systems, and software engineering.

## Overview

This portfolio highlights engineering and software projects spanning:

* Computer vision and real-time tracking systems
* Embedded control and robotics
* ROS-based autonomous platforms
* Machine learning and perception pipelines
* Signal processing and Fourier analysis

The site was designed and built from scratch using HTML and CSS with a focus on clean layout, responsive design, and interactive project presentation.
