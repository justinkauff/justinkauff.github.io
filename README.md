# Justin Kauff Portfolio

Personal portfolio website showcasing projects, research, and technical experience in robotics, reinforcement learning, computer vision, embedded systems, and software engineering.

## Overview

This portfolio highlights engineering and software projects spanning:

* Humanoid and quadruped robotics (ROS / ROS 2, Unitree G1 and Go1)
* Reinforcement learning in simulation (PPO, MuJoCo)
* Computer vision and real-time tracking systems
* Embedded control, sensing, and haptic feedback hardware
* Electromagnetic instrumentation and signal analysis

The site is a single-page, responsive layout built with HTML, CSS, and vanilla JavaScript (scroll animations and a lightweight photo carousel), hosted on GitHub Pages.

## Featured Projects

* Combat Humanoid RL on the Unitree G1 (REK × RISE Lab)
